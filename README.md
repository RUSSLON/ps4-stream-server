# PS4 Stream Mobile v0.3 — Android + каталог HDrezka + VLC

**Состояние: исходный проект для первой экспериментальной сборки, не APK.**

## Что уже есть в исходниках

- Нативная оболочка Kotlin/Jetpack Compose: **Главная / Каталог / Поиск / Моё / PS4**.
- Каталог из реального Python-адаптера `HDrezka` (неофициальная библиотека), поиск по названию и по страницам, постеры, жанры и доступные метаданные.
- Новинки: первая страница категорий «Фильмы» и «Сериалы». Это **не точная копия верхней ленты сайта**, пока библиотека не выдаёт такую ленту явно.
- Адаптивная сетка, подробная карточка, фиолетовая палитра, картинка-баннер, темы Android, кеш изображений Coil.
- Избранное, «Буду смотреть», история, история поисков, сохранённые фильтры, экспорт/импорт библиотеки в JSON.
- Попытка открыть полученный видео-URL **во внешнем VLC**, запасной выбор другого установленного видеоплеера.
- Отправка фильма на существующий `https://ps4-stream.onrender.com/` с 4-значным PIN через **старый рабочий** `RenderClient`.
- Резервный **«Совместимый режим HDrezka»** — старый WebView с выбором озвучек, сезонов, серий, качества, субтитров, отправкой PS4; сюда добавлена кнопка `▶ СМОТРЕТЬ В VLC`.
- API_KEY продолжает храниться в Android Keystore. На Python-каталоге выдача видеоссылок защищена тем же Bearer-ключом.

## Что *пока не готово*

- Полностью нативный выбор сезонов и серий; для сериалов открывается прежний экран WebView. **Серверный `stream` пока поддерживает только фильмы**, не сериал с неизвестным эпизодом.
- Глобальная фильтрация по стране/рейтингу/озвучке, расширенные сортировки: применяются только по загруженным карточкам, а озвучка становится известна после открытия фильма.
- Уведомления Android о новых сериях, офлайн-скачивание, автоматическая позиция VLC, личные рекомендации, синхронизация точного таймкода на PS4.
- Рабочая проверка онлайн на HDrezka/Render и сборка APK **не проводились в этой среде**: здесь нет Android SDK, а внешний Python-пакет и сайт недоступны из контейнера. Тесты backend используют имитацию библиотеки.
- Полученные сервером CDN-ссылки **могут оказаться IP-привязанными к Render** и не воспроизводиться на телефоне (HTTP 404). В таком случае открой фильм в совместимом режиме и нажми VLC: там ссылка запрашивается непосредственно телефоном.

## Почему два сервера

1. **Прежний Render-сервер** `https://ps4-stream.onrender.com/` остается нетронутым. Он отвечает за PIN и PS4-плеер.
2. **Новый сервис каталога**, например `https://ps4stream-catalog.onrender.com/`, выполняет Python-библиотеку `HDrezka`, возвращает JSON с фильмами и разрешёнными потоками. Адрес выдаётся Render после деплоя — не нужно предполагать заранее конкретный URL.

## Создание каталога на Render

1. Создай **отдельный GitHub-репозиторий** для этого проекта (в корне должны быть `render.yaml`, `catalog-server/`, `app/`).
2. В Render нажми **New → Blueprint**, выбери новый репозиторий. Render прочтёт `render.yaml` и предложит web service `ps4stream-catalog`. Можно создать web service вручную с `Root directory = catalog-server`, Build Command = `pip install -r requirements.txt`, Start Command = `python app.py`.
3. Установи **Environment**: `CATALOG_API_KEY` = **точно тот же сильный API_KEY**, который уже настроен у прежнего Render PS4-сервера. Секрет не добавляй в GitHub, не вставляй в код.
4. Запусти деплой. Проверка доступности: `https://<адрес-нового-сервиса>/health` должна возвращать `{"ok": true,...}`.
5. API каталога: `/api/home`, `/api/catalog?category=films&page=1`, `/api/search?q=...`, `/api/detail?url=...`, `/api/stream?...`. Последний требует HTTP `Authorization: Bearer ...`.
6. Если библиотека перестала работать из-за блокировки сайта, сервер вернёт HTTP 502. Это **не лечится Android-перекомпиляцией**: потребуется проверить сайт/зеркало и совместимость Python-библиотеки.

Важно: библиотека `HDrezka` **неофициальная**. Исходный репозиторий: https://github.com/kristal374/hdrezka-api ; в `catalog-server/requirements.txt` указан его GitHub URL, поскольку `pip install --upgrade hdrezka-api` из PyPI нельзя считать надёжной командой без проверки конкретного пакета.

## Как собрать APK (Mac, Android Studio)

1. Распакуй **полный** ZIP и открой именно корневую папку `PS4Stream-Mobile-v0.3` через **Android Studio → Open**.
2. В **SDK Manager** установи **Android API 35**. Выбери **Gradle JDK 21**.
3. Gradle = **8.13**, AGP = **8.13.2**, Kotlin = **2.4.21**, используется новый `compilerOptions` (старой ошибки `jvmTarget: String` уже нет).
4. В этом ZIP, как и в старом проекте, **нет `gradlew` и `gradle-wrapper.jar`**. Если Android Studio запросит Gradle Wrapper, настрой установленный Gradle 8.13 через настройки Gradle либо сгенерируй wrapper локальной Gradle-командой. **На GitHub Actions Wrapper не нужен**, workflow сам устанавливает Gradle.
5. **File → Sync Project with Gradle Files**, затем **Build → Build APK(s)**.
6. При `BUILD SUCCESSFUL` APK лежит в `app/build/outputs/apk/debug/app-debug.apk`.

## Как собрать на GitHub Actions без Android Studio

**Actions → Build Android APK → Run workflow** → после успеха скачай артефакт `PS4Stream-Mobile-v0.3-debug`. Файл внутри артефакта — `app-debug.apk`. Запуск Action ещё не проверен.

## Первый запуск

1. Внизу открой вкладку **PS4 (настройки)**.
2. В `Сервер каталога` вставь **реальный** HTTPS URL нового сервиса каталога на Render. Нажми **Подключить каталог**.
3. Введи `API_KEY` и нажми **Сохранить API_KEY**. Этот ключ нужен также для получения видеоссылок у твоего собственного каталога.
4. Нажми **Проверить PIN на демо-видео** — можно убедиться, что старый Render работает.
5. Открой «Главная», выбери фильм, озвучку, качество, **Смотреть на телефоне · VLC**. Установи VLC из Google Play, если не установлен.
6. **Смотреть на PlayStation** отправляет видео на старый Render, показывает PIN в разделе PS4. При ошибках IP-привязки используй «Совместимый режим» и кнопку «▶ СМОТРЕТЬ В VLC» — этот режим запрашивает ссылку с устройства.

## Если обновляешь прежний Android проект, а не создаёшь новый

В архиве обновления находятся **только** заменяемые/новые файлы: корневой Gradle-файл, Gradle модуля, манифест, `MainActivity.kt`, новые `LegacyActivity.kt`, `CatalogClient.kt`, `LocalLibrary.kt`, `VlcLauncher.kt`, каталог Python, CI, README, `render.yaml`. Существующие `RenderClient.kt`, `SecureKeyStore.kt`, `AppConfig.kt`, `rezka_adapter.js` остаются прежними.

Для доступа к медиа должны существовать необходимые права; проект не отключает DRM, не подменяет авторизацию и не гарантирует доступность каждого потока.
